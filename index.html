Privacy Policy

Application: VAP OS Publisher (Meta App ID: 3292835964437949)
Last Updated: September 20, 2026
Summary: VAP OS Publisher is a private marketing automation command center operated by the owner for managing connected brand pages (including WineSip). We strictly adhere to Meta Platform Policies, collect only necessary page management tokens and public performance metrics, and never sell, share, or rent your personal data.

1. Introduction

This Privacy Policy describes how VAP OS Publisher ("we", "us", "our", or "the Application") collects, uses, stores, and protects information when interacting with social media platforms via official APIs, including the Meta Graph API (Facebook and Instagram).

The Application is a specialized operating system utilized for brand marketing automation, content scheduling, and campaign performance analytics.

2. Information We Access and Collect

We only request and access permissions and data necessary to provide social media publishing and analytics services. The data collected through official Meta Graph APIs includes:

  • Page Identifiers & Metadata: Facebook Page ID, Page Name, connected Instagram Business Account ID, and profile picture links for authenticated brand assets.
  • Access Credentials: Short-lived and permanent Page Access Tokens generated through official OAuth authentication. We never request, store, or have access to personal user passwords.
  • Content Data: Post captions, hooks, creative media links, and scheduling timestamps created or managed through the application.
  • Analytics & Engagement Metrics: Aggregate and public post metrics, including Reach (Alcance), Impressions / Views (Visualizaciones), Likes, Comments count, and Shares.

3. How We Use the Information

The information accessed through Meta and other platform APIs is strictly used for:

  • Publishing scheduled posts, images, and videos directly to authorized Facebook Pages and Instagram accounts.
  • Retrieving verified performance analytics to evaluate content reach, audience engagement, and campaign return-on-investment.
  • Maintaining system health and refreshing authentication credentials.

4. Data Sharing and Disclosure

We do not sell, rent, monetize, or disclose your data to third parties or data brokers.

Data is only processed through official infrastructure:

  • Meta Platforms, Inc.: Via official Meta Graph API endpoints according to the Meta Platform Terms.
  • Google Cloud / Firebase: For secure private database storage and authenticated session management.

5. Data Security and Storage

We employ industry-standard technical measures to secure all operational data:

  • All API requests are transmitted over encrypted HTTPS/TLS connections.
  • Access tokens and credentials are securely isolated with role-based database security rules.
  • No unauthorized public or multi-tenant access is permitted.

6. Data Retention and Deletion Rights

We retain operational metrics and tokens only for as long as needed to fulfill the marketing and analytics functions.

You have the right to request deletion of any associated data at any time. For full instructions on how to request the removal of your data or revoke application permissions via Facebook, please review our User Data Deletion Instructions.

7. Compliance with Meta Platform Terms

This application complies with:

  • Meta Platform Terms
  • Meta Developer Policies
  • General Data Protection Regulation (GDPR) and California Consumer Privacy Act (CCPA) principles regarding data minimization and privacy.
